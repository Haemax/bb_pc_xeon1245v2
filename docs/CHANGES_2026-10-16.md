# Changes, 2026-10-16

Ported from the Windows port (Mrsuss60/bloodborne_pc_windows_port), where they fit the Linux tree.

## Mouse look (`src/runtime_pad.c`, launcher)
- `mouse_smoothing=0..0.95` in `bbport.ini` (launcher: *Mouse smoothing*): an exponential filter on
  the mouse motion. Its strength is per 1/60 s, so the smoothing lasts the same time at 60 and at
  240 samples a second (the Windows port filters per sample). The filter keeps the total motion.
  0, the default, is the raw behaviour as before.
- `mouse_sensitivity_x` / `mouse_sensitivity_y` (one axis each; `mouse_sensitivity` sets both, later
  lines win), `mouse_invert_x` (launcher: *Invert mouse X axis*).
- The same settings in the environment (`BB_MOUSE_SENSITIVITY`, `_X`, `_Y`, `BB_MOUSE_SMOOTHING`,
  `BB_MOUSE_INVERT_X`, `BB_MOUSE_INVERT_Y`) override the file, for tests.
- Not ported: the Windows port's Shift+mouse chords (here Shift is Circle/dodge by default, so the
  chord would roll while attacking) and its press-to-rebind UI (the launcher's *Controls* does that).

## Audio (`src/runtime_audio.c`)
- Soft-knee limiter on the output (linear to 0.8, then bending to 1.0 with no corner): a mix that
  peaks past full scale is no longer cut flat. Nothing below 0.8 changes. `BB_AUDIO_SOFTCLIP=0`: off.
- `BB_AUDIO_PREFILL=N` (1–8, default 2): buffer periods the queue is steered to hold. Raise it to 3–4
  if the audio crackles when the CPU is the bottleneck.
- The underrun count (the queue ran below one buffer) is printed with the audio summary at exit.
- Not ported: the Windows port's default 1.4x output boost and its per-layout master gain; they
  change the loudness of the whole game.

## Kernel (`src/runtime_kernel.c`)
- `BB_NCPU=N` (1–64) sets the `hw.ncpu` the game reads (7, the PS4's game cores, by default).

## Tools
- `tools/frame_summary.py`: FPS, frame-time percentiles, 1 % / 0.1 % lows, stutter counts and a
  GPU-bound / CPU-bound verdict from a `BB_FRAME_LOG` csv (the launcher's *Save the log and
  statistics to a file* writes one). `--compare` for A/B runs, `--skip` for the first seconds.

## Tests
- `tests/test_pad.c`: the settings' parsing and limits, the environment override, axis inversion,
  separate sensitivities, and the smoothing filter (total motion kept, same spread at 60 and 240 Hz).
